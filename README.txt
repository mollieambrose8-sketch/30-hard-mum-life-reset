# 30 Hard Mum-Life Reset

A mobile-first, blush-pink and sage-green habit tracker PWA.

## Files
- `index.html`: app
- `manifest.json`: installable app metadata
- `service-worker.js`: offline cache
- `icon-192.png`, `icon-512.png`: app icons

## Publish it for free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. `mum-life-reset`.
3. Upload all five files from this folder to the repository root.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to provide the website URL.
7. Open that URL in Safari on your iPhone, tap Share, then “Add to Home Screen”.

Use HTTPS hosting for installability/offline support. Progress is saved in browser local storage on that device; it is not synced between devices. Export or back up journal content separately if needed.
